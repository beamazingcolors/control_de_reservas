Alertas Críticas de Cobros Pendientes

Alertas tempranas para servicios próximos a ejecutarse y cuentas vencidas que no registran estatus al corriente.

Reglas del Sistema de Alertas

  • Se genera una alerta de nivel crítico si la fecha del servicio ya ha pasado, la cuenta no se encuentra conciliada y registra saldo pendiente de pago.
  • Se genera una alerta preventiva si el servicio se ejecuta en los próximos 2 días y aún no se ha liquidado el total.
  • Toda reserva con estatus Al Corriente queda excluida automáticamente del flujo de notificaciones.

Vincular con tu Google Sheet Autorizado

Integra el formulario directamente con tu hoja de cálculo dedicada por medio de un script en Google Apps Script.

¡ALERTA DE CONEXIÓN IMPORTANTÍSIMA!

El error número uno por el cual los datos no se ven reflejados en la hoja de cálculo de Google es pegar la dirección del navegador de Google Sheets https://docs.google.com/spreadsheets/d/... en el campo Web App URL.
Lo que debes pegar en el formulario de abajo es la dirección del Servicio Web App generado tras presionar "Nueva Implementación" en Apps Script (que inicia con https://script.google.com/macros/s/...). Por favor sigue detenidamente los pasos indicados a la derecha.

URL de Implementación Apps Script

Sincroniza y vacía de forma automatizada toda la información recopilada de cada reserva directamente en la siguiente hoja de cálculo de Google Drive:

Google Sheet Destinatario (Autorizado) https://docs.google.com/spreadsheets/d/1P26hTp6eNue9FZiPyF500ufIp1MOgM7vtwTsWg2DtHU/edit?usp=sharing

Instrucciones de Vinculación Paso a Paso

  1. Abre tu hoja de cálculo autorizada haciendo clic en el enlace azul a la izquierda.
  2. Dentro de tu hoja de cálculo, ve al menú superior y selecciona Extensiones > Apps Script.
  3. Sustituye todo el código por el bloque de abajo y presiona Guardar.
  4. Haz clic en Implementar > Nueva implementación (esquina superior derecha).
  5. Selecciona el tipo Aplicación Web. Configura "Ejecutar como: Tú" y "Quién tiene acceso: Cualquiera" (Anyonene).
  6. Haz clic en Implementar, copia la URL de la aplicación web (la cual inicia con https://script.google.com/macros/s/...) y pégala a la izquierda.
Código Apps Script Completo 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // Lectura robusta de payloads en formato JSON o URL-encoded (no-cors)
    var data;
    if (e && e.postData && e.postData.contents) {
      try {
        data = JSON.parse(e.postData.contents);
      } catch (jsonError) {
        data = e.parameter;
      }
    } else if (e && e.parameter) {
      data = e.parameter;
    } else {
      throw new Error("No se recibieron datos de entrada legibles.");
    }
    
    // Si la hoja está vacía, añade encabezados de columnas
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Fecha Registro", "Cliente", "Tour", "Proveedor", "Fecha Servicio", 
        "Pax", "Check-in", "Check-point", "Confirmacion", "Vendedor", 
        "Moneda", "Tipo Cambio", "Balance", "Balance MXN", "Reporte MXN", 
        "Diferencia MXN", "Quien Debe", "Monto Deuda MXN", "Estatus"
      ]);
    }
    
    sheet.appendRow([
      new Date(),
      data.nombre || "",
      data.tour || "",
      data.provedor || "",
      data.fecha || "",
      Number(data.pax) || 0,
      data.checkIn || "",
      data.checkPoint || "",
      data.confirmacion || "",
      data.vendedor || "",
      data.moneda || "",
      Number(data.tipoCambio) || 1.00,
      Number(data.balance) || 0,
      Number(data.balanceMxn) || 0,
      Number(data.reporte) || 0,
      Number(data.diferencia) || 0,
      data.quienDebe || "",
      Number(data.cuantoDebe) || 0,
      data.status || ""
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({"result": "error", "error": error.toString()}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
