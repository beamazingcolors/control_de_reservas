Alertas Críticas de Cobros Pendientes

Alertas tempranas para servicios próximos a ejecutarse y deudas activas vencidas.

Reglas del Sistema de Alertas

  • Se genera una alerta de nivel crítico si la fecha del servicio ya ha pasado, la cuenta no se encuentra conciliada y registra saldo pendiente de pago.
  • Se genera una alerta preventiva si el servicio se ejecuta en los próximos 2 días y aún no se ha liquidado el total.
  • Toda reserva con estatus Al Corriente queda excluida automáticamente del flujo de notificaciones.

Sincronización en la Nube con GitHub

Guarda tus reservas directamente en tu repositorio seguro de GitHub como un archivo JSON dinámico.

💡 ¿Por qué GitHub es mejor y 100% confiable?

Al enlazar un archivo `.json` de GitHub, tu información se almacena con alta seguridad, en tiempo real, con historial de cambios y sin cortes de red.

Credenciales de tu Repositorio

¿Cómo obtener tus credenciales de GitHub?

  1. Entra a tu cuenta en GitHub y crea un repositorio (público o privado).
  2. Ve a tu **Perfil > Settings > Developer Settings > Personal Access Tokens > Tokens (classic)**.
  3. Genera un nuevo token con permisos mínimos de escritura en tus repositorios (marca únicamente la casilla **`repo`** o **`public_repo`**).
  4. Copia el token que inicia con ghp_... y pégalo en la casilla de la izquierda.
  5. Define la ruta del archivo y presiona **Guardar**.
